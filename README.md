# sumtrip-legal

Rechtliche Hinweise zur **Sumtrip**-App (Datenschutzerklärung und Impressum).

Dieses Repo enthält ausschließlich statische HTML-Seiten und wird über GitHub
Pages veröffentlicht, weil Google Play eine öffentlich erreichbare
Datenschutz-Adresse verlangt. Der App-Quellcode liegt in einem separaten,
privaten Repo.
